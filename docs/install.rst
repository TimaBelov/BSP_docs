Установка
=========

1. Установить `.NET 11.0 Desktop Runtime`_ **x86** (программе нужны ``Microsoft.NETCore.App`` и
   ``Microsoft.WindowsDesktop.App`` версии 11.0). Нужна именно 32-битная версия (x86), даже на
   64-битной Windows: программа 32-битная из-за драйвера считывателя Chafon CF810.
2. Скачать_ архив с программой и распаковать его в нужную папку на диске.
3. Запустить ``BelovSportProgram.exe``.

.. _`.NET 11.0 Desktop Runtime`: https://dotnet.microsoft.com/en-us/download/dotnet/11.0
.. _Скачать: https://disk.yandex.ru/d/nlPWrc6bFqnykg

.. note::
   | Программа работает под Windows 10 и 11.
   | .NET 11 требует процессор с поддержкой SSE4.2 и POPCNT (x86-64-v2). Подходят почти все
     процессоры, выпущенные после 2010 года; на очень старых ноутбуках программа не запустится.
   | Протоколы сохраняются в HTML и открываются в браузере по умолчанию.
   | Окну «Оффлайн результаты» нужен WebView2 — он уже установлен в Windows 10/11. Если окно не
     открывается, установите
     `Microsoft Edge WebView2 Runtime <https://developer.microsoft.com/microsoft-edge/webview2/>`_.

Состав архива
-------------

Основное, что нужно знать о папке с программой:

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Файл / папка
     - Назначение
   * - ``BelovSportProgram.exe``
     - Запуск программы
   * - ``Templates/``
     - Шаблоны документов: номер (``bib.html``), стили протоколов (``protocol.css``,
       ``style.html``, ``reset.css``), стартовая шахматка (``start_chess.html``),
       онлайн-результаты (``forOnline.html``), логотип (``logo.png``) и др.
       Шаблоны можно править под свои соревнования.
   * - ``wkhtmltox/``
     - Конвертер HTML → PDF: печать сплитов, номеров, чеков мандатной комиссии и награждения
   * - ``SumatraPDF-3.6-64.exe``
     - Тихая печать PDF на принтер
   * - ``Logs/``
     - Журналы обмена с orgeo.ru (``orgeo-ГГГГ-ММ-ДД.log``) и ошибок программы
       (``crash-ГГГГ-ММ-ДД.log``) — пригодятся при разборе проблем

Настройки этого компьютера хранятся не в папке программы, а в
``%APPDATA%\BelovSportProgram``:

* ``local-settings.json`` — COM-порт RFID, номер текущей антенны, папка логотипов;
* ``rfid-journal.sqlite`` — локальный журнал RFID-считок (см. :doc:`results`);
* ``SponsorLogos`` — папка логотипов спонсоров по умолчанию.

Файл соревнований
-----------------

Все данные соревнований хранятся в одном файле с расширением ``.bsp`` (база SQLite).
Его удобно копировать и делать резервные копии.

При открытии файла, созданного старой версией программы, BSP сам обновит структуру файла
и предварительно сохранит **резервную копию** рядом с исходным файлом, с именем вида
``<имя>_backup_v<N>_ГГГГММДД_ЧЧММСС.bsp`` (путь к ней будет показан в сообщении).
Файл, созданный более новой версией, старая версия не откроет — обновите программу.

Обновление программы
--------------------

Распакуйте новый архив поверх старого или в новую папку.

.. warning::
   С ноября 2026 г. программа собрана под **.NET 11** (раньше был .NET 8, его поддержка
   закончилась 10 ноября 2026 г.). Перед первым запуском новой версии установите
   `.NET 11.0 Desktop Runtime`_ x86 на каждый компьютер, где работает BSP. Без него Windows
   покажет окно «You must install or update .NET to run this application». .NET 8 можно не
   удалять: он не мешает.

Файлы соревнований ``.bsp``
хранятся отдельно и при обновлении не затрагиваются. Если вы правили шаблоны в папке
``Templates``, сохраните их перед обновлением.
