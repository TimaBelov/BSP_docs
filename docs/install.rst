Установка
=========

1. Установить `.NET 8.0 Desktop Runtime`_ (программе нужны ``Microsoft.NETCore.App`` и
   ``Microsoft.WindowsDesktop.App`` версии 8.0).
2. Скачать_ архив с программой и распаковать его в нужную папку на диске.
3. Запустить ``BelovSportProgram.exe``.

.. _`.NET 8.0 Desktop Runtime`: https://dotnet.microsoft.com/en-us/download/dotnet/8.0
.. _Скачать: https://disk.yandex.ru/d/nlPWrc6bFqnykg

.. note::
   | Программа работает под Windows.
   | Для просмотра протоколов используется WebView2 — он уже установлен в Windows 10/11.
     Если окна предпросмотра не открываются, установите
     `Microsoft Edge WebView2 Runtime <https://developer.microsoft.com/microsoft-edge/webview2/>`_.

Состав архива
-------------

Основное, что нужно знать о папке с программой:

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Файл / папка
     - Назначение
   * - ``BelovSportProgram.exe``
     - Запуск программы
   * - ``Templates/``
     - Шаблоны документов: номер (``bib.html``), стили протоколов (``protocol.css``),
       онлайн-результаты (``forOnline.html``), диплом (``диплом.docx``), логотип и др.
       Шаблоны можно править под свои соревнования.
   * - ``wkhtmltox/``
     - Конвертер HTML → PDF, используется для печати сплитов
   * - ``SumatraPDF-3.6-64.exe``
     - Тихая печать PDF на принтер
   * - ``Logs/``
     - Журналы обмена с orgeo.ru (``orgeo-ГГГГ-ММ-ДД.log``) — пригодятся при разборе
       проблем с отправкой
   * - ``local-settings.json``
     - Настройки этого компьютера (создаётся программой)

Файл соревнований
-----------------

Все данные соревнований хранятся в одном файле с расширением ``.bsp`` (база SQLite).
Его удобно копировать и делать резервные копии.

При открытии файла, созданного старой версией программы, BSP сам обновит структуру файла
и предварительно сохранит **резервную копию** (путь к ней будет показан в сообщении).
Файл, созданный более новой версией, старая версия не откроет — обновите программу.

Обновление программы
--------------------

Распакуйте новый архив поверх старого или в новую папку. Файлы соревнований ``.bsp``
хранятся отдельно и при обновлении не затрагиваются. Если вы правили шаблоны в папке
``Templates``, сохраните их перед обновлением.
