Belov Sport Program
===================

**Belov Sport Program (BSP)** — программа для проведения соревнований по спортивному
ориентированию: от приёма заявок и жеребьёвки до считывания чипов, печати сплитов,
онлайн-результатов на orgeo.ru и официальных протоколов.

Документация актуальна на 6 ноября 2026 г.

.. note::
   | По вопросам: VK_ TG_

.. _VK: https://vk.com/tttbba
.. _TG: https://t.me/tttbba

Что умеет программа
-------------------

* соревнования в заданном направлении, по выбору, эстафеты (в том числе эстафеты, где
  один участник бежит все этапы), многодневки с суммой дней;
* импорт участников из CSV (выгрузка orgeo.ru) и дистанций из OCAD 8 и Purple Pen (IOF XML v3);
* жеребьёвка по стартовым коридорам с резервом, разведением одноклубников и автоматической
  выдачей номеров;
* мандатная комиссия: проверка документов, оплата наличными/картой, печать чека, справки;
* регистрация на старте, печать номеров, запись номера в чип SFR;
* считывание чипов SFR и UHF RFID-меток (Chafon CF810) с нескольких компьютеров;
* печать сплитов (в т.ч. на чековый принтер ESC/POS), печать для награждения;
* стартовые протоколы, протоколы результатов, командные результаты, суммы дней, дипломы;
* официальные протоколы по ЕВСК с расчётом выполненных разрядов;
* отправка стартовых протоколов и результатов на orgeo.ru (в том числе онлайн).

**Поддерживает работу с полным ФИО и полной датой рождения спортсменов.**
