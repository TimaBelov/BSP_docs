Эстафеты
========

Поддерживаются два типа эстафет (тип дистанции в карточке группы):

* **Эстафета** — команда из нескольких участников, каждый бежит свой этап;
* **Эстафета одного участника** — один участник бежит все этапы.

Ввод эстафетных команд
----------------------

1. Выберите день, когда проходит эстафета, и в карточке группы укажите **Количество
   эстафетных этапов**.

   .. image:: ../screens/relay_2.jpg

2. Откройте ``Подготовка к старту -> Ввод эстафетных команд``.
3. В форме доступен фильтр участников по группе и поиск по фамилии/команде. Галочка
   ``Скрыть уже забитых`` прячет участников, которые уже в командах.

   .. image:: ../screens/relay_1.jpg

4. Двойной клик по участнику в верхней таблице добавляет его в состав команды.
5. Порядок этапов меняется кнопками ``Выше`` / ``Ниже``, участника можно убрать из состава.
6. Задайте **Номер команды** и нажмите ``Сформировать команду``. Номер команды автоматически
   увеличится на 1 для следующей команды.

   .. image:: ../screens/relay_.jpg

Жеребьёвка и номера
-------------------

После формирования команд распределите эстафетные группы в жеребьёвке
(см. :doc:`draw`). Программа автоматически присвоит номера командам и этапам.

Номер этапа хранится в программе в виде ``1301`` (этап 1, команда 301), а в протоколах и на
сайте выводится как ``301.1``.

Результаты
----------

Протокол результатов эстафеты формируется по командам: общее время команды, время и место на
каждом этапе.
